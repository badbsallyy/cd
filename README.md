# Aura - AI Website Builder

A fully functional landing page built with Astro, featuring modern UI components, smooth animations, and responsive design.

## 🚀 Features

- **Modern UI Components**: Header, Hero section with floating cards, Features grid, Call-to-action, Footer
- **Smooth Animations**: Fade-in, slide-down, float, and pulse effects
- **Fully Responsive**: Adapts to all screen sizes from mobile to desktop
- **SEO Optimized**: Complete meta tags for search engines and social media
- **Performance**: Built with Astro for lightning-fast static site generation

## 🛠️ Tech Stack

- [Astro](https://astro.build/) - Static Site Generator
- HTML5 / CSS3
- JavaScript
- [Iconify](https://iconify.design/) - Icon system

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Components Overview
